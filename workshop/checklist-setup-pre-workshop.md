# Checklist de Setup — Pre-Workshop

> **VelaraLoop Academy · Workshop** · Se envía 48h antes al asistente.
> Objetivo: llegar al workshop con el agente listo (o saber qué dudas traer).

---

## 1. Computadora

- [ ] Laptop con internet (Windows / Mac / Linux)
- [ ] Permiso para instalar programas (o usar versión web si aplica)
- [ ] 30 min libres para el setup

## 2. Tu tarea (la traes al workshop)

Elige UNA tarea que hagas cada semana y te quite tiempo. Ejemplos:

- Armar un reporte (ventas, status, métricas)
- Procesar un archivo de datos (Excel/CSV)
- Escribir/resumir un documento (minuta, propuesta)
- Hacer una investigación o comparativa

> **Tip:** idealmente con un archivo de datos de prueba. Copia, no el original.

## 3. Preparar la carpeta (opcional pero recomendado)

- [ ] Crea una carpeta `MiAutomatizacion/` en tu escritorio
- [ ] Pon una COPIA de tus datos ahí (nunca el original)
- [ ] Sin datos sensibles (o máscara)

## 4. Instalar el agente (intenta antes del workshop)

### Opción A: Claude Code (recomendado para nuevos)

```bash
npm install -g @anthropic-ai/claude-code
claude
```

Necesitas una cuenta de Claude (plan Pro o API).

### Opción B: OpenCode (open source)

```bash
npm install -g opencode-ai
opencode
```

### Opción C: Cursor (ventana con botones)

Descarga de cursor.com → instala → "Abrir carpeta" → `MiAutomatizacion`.

### Opción D: Kiro

Sigue tu setup habitual de Kiro. Trabaja en `MiAutomatizacion`.

> **¿Se te complicó?** No pasa nada. Trae tu laptop y lo resolvemos juntos en el bloque de setup (30 min dedicados).

## 5. Verificación rápida (5 min)

- [ ] Abre el agente dentro de `MiAutomatizacion/`
- [ ] Pega: *"¿Qué archivos hay en esta carpeta? Lista cada uno. No cambies nada."*
- [ ] Si te lista los archivos → listo ✅
- [ ] Si no → anota la duda, la resolvemos en el workshop

---

## Dudas frecuentes

| Duda | Respuesta |
|------|-----------|
| "¿Voy a romper algo?" | No. Trabajas en `MiAutomatizacion/`, carpeta aislada. |
| "¿Necesito saber programar?" | No. Especificas. El agente ejecuta. |
| "¿Y si mi tarea es compleja?" | Empezamos con la versión chica; se itera. |
| "¿Cuánto cuesta el agente?" | OpenCode gratis; Claude Pro ~$20/mes. Cero para el workshop. |
