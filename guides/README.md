## Cómo usar estas guías

1. Lee **De Chat a Agente** y haz el setup (<30 min).
2. Abre la guía de **tu rol** y elige 1 tarea concreta.
3. Usa el **template** para escribir la especificación.
4. El agente ejecuta → tú verificas → iteras.

**Regla de oro:** empieza con una tarea chica y real de TU trabajo. Un éxito pequeño mata el miedo.
